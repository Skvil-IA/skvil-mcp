# CLAUDE.md

## Project Overview

skvil-mcp is a Model Context Protocol (MCP) server that provides AI agents with direct access to the Skvil security scanner API. It allows agents to verify skill safety, submit scan results, and check certifications without manual HTTP calls.

## Commands

```bash
npm install           # Install dependencies
npm run build         # Compile TypeScript to dist/
npm run dev           # Watch mode (auto-recompile)
npm run lint          # ESLint check
npm run format        # Prettier format
npm run format:check  # Prettier check
npm run typecheck     # TypeScript type check (no emit)
npm start             # Run the MCP server (stdio transport)
```

After cloning, run `npm run build` to generate `dist/`. The `dist/` directory is gitignored and regenerated by `prepublishOnly` during npm publish.

## Architecture

- `src/index.ts` — Entry point: creates McpServer, registers tools, connects stdio transport, handles SIGINT/SIGTERM
- `src/version.ts` — Single source of truth for package version (update here when bumping)
- `src/tools.ts` — All 6 MCP tool definitions with Zod schemas, handlers, `formatScore` (score-to-risk mapping), and `formatError` (structured error responses by status code)
- `src/api.ts` — HTTP client for api.skvil.com (native fetch, 15s timeout, retry with exponential backoff on 502/503/504)
- `src/config.ts` — API key resolution (env var → mcp-config.json → legacy config), memoized for process lifetime
- `src/types.ts` — TypeScript interfaces for API responses (must match skvil-kedavra backend models)

## Key Design Decisions

- **stdio transport** — standard for local MCP servers, spawned as subprocess by the AI client
- **Auto-registration** — `skvil_register` tool caches the API key in `~/.skvil/mcp-config.json`
- **Zero config** — works out of the box with `npx @skvil/mcp-server`
- **Native fetch** — no HTTP dependencies, Node 18+ built-in
- **Error handling** — all errors are caught and returned as structured MCP error content
- **HTTPS enforcement** — custom API URLs must use HTTPS (except localhost for dev)
- **Env var compatibility** — reads both `SKVIL_API_KEY` and `SKVIL_KEDAVRA_API_KEY` for cross-tool compatibility with the Python scanner
